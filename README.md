# HideFrames

A lightweight World of Warcraft addon that lets you hide almost any frame by name or `Parent.Child` path.

## Features
- Hide frames with `/hide FrameName` or `/hide Parent.Child`
- Multi-frame support: `/hide Frame1 Frame2 Parent.Child`
- Profiles
- Minimap button
- Simple GUI with checkboxes + remove buttons
- Frame name copier (`/fscopy`)

## Installation
Copy the `HideFrames` folder into your `Interface/AddOns` directory.
